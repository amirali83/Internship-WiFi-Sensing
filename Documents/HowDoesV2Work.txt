۱. حالت‌های اجرایی خط فرمان (یک‌بار اجرا و خاتمه)

    --benchmark: اجرای بنچمارک تشخیص تنفس و ضربان قلب روی ۱۰۰۰ فریم

    --convert-model: تبدیل مدل از فرمت Hugging Face (Safetensors/JSONL) به RVF

    --export-rvf: خروجی گرفتن فایل RVF با وزن‌های Placeholder (دمو)

    --pretrain: پیش‌آموزش خودآموز (Self-Supervised) با Contrastive Learning روی داده‌های بدون برچسب

    --embed: استخراج بردارهای ۱۲۸ بعدی (Embedding) از داده‌های CSI

    --build-index: ساخت ایندکس جستجو برای فینگرپرینت‌های محیطی

    --train: آموزش نظارت‌شده (Supervised) با داده‌های برچسب‌خورده پوز

۲. حالت عادی (سرور اصلی - بدون فلگ خاص)

دریافت داده:

    UDP Receiver: دریافت داده‌های CSI از سنسورهای ESP32 از طریق پورت UDP

    Windows WiFi: دریافت داده‌های RSSI از WiFi لپ‌تاپ در ویندوز

    Simulated Data: تولید داده‌های شبیه‌سازی‌شده برای دمو و تست

    Auto Detect: تشخیص خودکار منبع داده (ESP32 → WiFi → Simulated)

پردازش و استخراج ویژگی:

    Feature Extraction: استخراج ۸ ویژگی اصلی از داده‌های خام CSI

    Vital Signs: تشخیص تنفس (۶-۳۰ BPM) و ضربان قلب (۴۰-۱۲۰ BPM)

    Pose Estimation: تخمین ۱۷ نقطه کلیدی بدن با معماری WiFlow

    Person Detection: تشخیص و شمارش افراد حاضر در محیط

    Activity Recognition: تشخیص حرکت، سقوط، نشستن، خوابیدن و ...

    Multistatic Fusion: ترکیب داده از چند سنسور برای دقت بیشتر

مدیریت مدل:

    Load Model: بارگذاری مدل از فایل RVF با قابلیت Progressive Loading

    SONA Profiles: مدیریت پروفایل‌های LoRA برای تطبیق با محیط‌های جدید

    Adaptive Classifier: طبقه‌بند تطبیقی که با محیط جدید یاد می‌گیرد

    Model Management: لیست، بارگذاری، حذف و فعال‌سازی مدل‌ها

خروجی و ارتباط با کاربر:

    WebSocket (پورت ۸۷۶۵): ارسال داده‌های لحظه‌ای به رابط کاربری

    REST API (پورت ۸۰۸۰): ارائه داده به صورت درخواستی با بیش از ۲۰ اندپوینت

    MQTT Publisher: اتصال به Home Assistant و سیستم‌های خانه هوشمند

    RVF Export: ذخیره وضعیت مدل و داده‌ها در فایل خروجی

مدیریت و ابزارها:

    Recording: ضبط داده‌های CSI برای استفاده در آموزش

    Calibration: کالیبراسیون محیط خالی برای افزایش دقت

    Edge Registry: مدیریت و نصب ماژول‌های WASM روی سنسورها

    Training API: آموزش مدل از طریق API (ADR-186)

    Introspection: نمایش وضعیت داخلی مدل برای عیب‌یابی

امنیت و اعتبارسنجی:

    Bearer Authentication: احراز هویت با توکن روی APIها

    OAuth: احراز هویت با Cognitum OAuth (ADR-271)

    Host Validation: محافظت در برابر حملات DNS Rebinding

    Field Signing: امضای دیجیتال داده‌ها با کلید Ed25519

    WS Ticket: صدور توکن یک‌بارمصرف برای WebSocket

 توضیح بعضی بخش های حالت های اجرای خط فرمان: 
 
 --PreTrain:
 ۱- اول از همه میاد دیتا هایی رو از جایی میخونه یا خودش دیتا درست میکنه.
 ۲- بعدش میاد 224 مقدار رو ۴ * ۵۶ رو از transformer و بعد از GNN و بعد از Projection رد میکنه.
 Flow 4 * 56 =  224 |||| -> 64 -> 64 -> 64 -> |||| 64 -> 64 -> |||| 128 -> 128 -> |||| 128
        CSI in    start Transformer           start GNN         start Projection   
بعد از این که به ۱۲۸ خروجی رسیدیم حال برای هر استفاده ای که میخوایم بکنیم مثل pose, people counting, vital signs, activity recognition, ... از decoder مخصوص خودش استفاده میکنیم.  
هرکدوم از این decoder ها خودشون یک شبکه عصبی سبک تر هستند.
نکته ای که اینجا مهمه اینه که ما داریم pretrain میکنیم بدون هیچ lablel \س این اصلا به چه دردیمون میخوره؟ کاری که میایم میکنیم اینه که از بک چیز دو تا شبیه هم درست میکنیم و بهم دلمون میگیم این دو تا به هم دیگه شبیه هستن و این دو تا با بقیه چیز هایی که توی مدل میبینی متفاوت هستند یه کاری کن که این دو تا به هم نزدیک و از بقیه چیزهایی که هستند فاصله داشته باشند. بعد از اتمام کار ما یک مدل داریم که تونسته دسته بندی و cluster بکنه یعنی میدونه کدوم دیتا ها با هم دیگه نزدیک هستن و کدوم ها از هم دیگه دور هستن ولی نمیدونه که هر گروه چی هستش اصلا \س با یک مرحله train کردن میاد و به این دسته های مختلف label اختصاص میده.
به این روش self supervised learning میگن. 
--Embed:
به مدلی که pretrain و train شده یک csi میده و اون ۱۲۸ عدد خروجی رو میگیره.
--build-index:
برای یک مدل pretrain و train شده. یک csi میگیره و embed میکنه و میاد و با با یک لیست از Embed ها که label گذاری شدن مقایسه میکنه و شماره اون هایی که نزدیک هستند اعدادشون به این رو برمیگردونه. با نگاه کردن به این اعداد و label های متناظرشون میتونیم بفهمیم که این csi داشته چیکار میکرده.
--Train:
برخلاف pretrain دارای label هست ولی ساختار کلی ان بسیار شبیه به pretrain هست. 
این مدل یک مدل supervised learning هست.
می تواند بدون دیتاهای اولیه pretrain اجرا بشود ولی خیلی منطقی نیست.
